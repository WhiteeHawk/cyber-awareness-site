#  Cyber Awareness Platform

##  Summary

A web-based platform designed to educate users about cybersecurity risks, improve their awareness, and provide practical tools to enhance their online safety.

##  Key Features

*  **Password Tools**: Check password strength and generate secure passwords
*  **Educational Content**: Simple explanations of cybersecurity threats (phishing, hacking, etc.)
*  **Cybersecurity News**: Latest updates on security threats and trends
*  **Policy Summaries**: Easy-to-understand usage and privacy policies
*  **Interactive Quizzes**: Test and improve users’ cybersecurity knowledge

##  Purpose

To help users stay safe online by combining awareness, education, and practical security tools in one platform.

##  Technologies

HTML, CSS, JavaScript
